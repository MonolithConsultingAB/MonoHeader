Privacy and permissions

MonoHeader has no remote service, telemetry, or third-party network client.

Local configuration
  • ✓
    No remote services

    No analytics, telemetry, accounts, cloud sync, update checks, or external API calls.

  • ✓
    Local and session storage

    Configuration, keep-alive presets, and audit data use the browser’s local extension storage. Values marked session-only use in-memory extension session storage and are never included in exports or rollback snapshots.

  • ✓
    Purpose-limited access

    Website access is used only for enabled header rules and session keep-alive tabs or site patterns selected by you.

  • ✓
    No page inspection

    Keep-alive uses a transient packaged function. Optional activity mode dispatches events to the document itself but does not query elements or read page text, form data, passwords, cookies, or response bodies.

Request-header values are sent to matching destinations. Session keep-alive can send a credentialed GET to the current page or your configured same-origin HTTPS path, dispatch a synthetic document-level activity pulse, or do both. Response content is discarded, and nothing is sent to a MonoHeader or third-party service.
